# Institute photography

Drop the institute's own licensed photos here to replace the
temporary CDN stand-ins — no code change needed beyond the
`src` values in `src/data/images.ts`:

- `hero.jpg` — computer classroom / training session (hero)
- `about.jpg` — students learning with instructor
- `practical.jpg` — learners practising in the lab
- `learn-today.jpg` — bright classroom, instructor teaching
- `ai.jpg` — technology / AI learning imagery
- `gallery-1.jpg` … `gallery-6.jpg` — lab, mentoring, practice, code, design

Accepted formats: `.jpg`, `.jpeg`, `.png`, `.webp`.
Keep each file under ~300 KB (compress with Squoosh / TinyPNG).
Recommended widths: 1600px hero, 1200px sections, 900px gallery.
